## 日本語訳

### VII. 結論

本稿は、固定した多段予測器に対する、圧縮残差状態を用いる端点保持型オンライン補正 EPOC を提案した。各予測対象ブロックの正解がそろった後、基準予測器の残差の低次 DCT 係数と末尾値を保持する。この末尾値を、現在予測の係数も受け取る成分別のオンライン ridge 回帰で共有する。八系列・二つの基準予測器にわたる対応する固定基準予測器の96条件で、完全な補正による Static 比の条件別 MSE・MAE 低減率は、平均でそれぞれ15.40%・9.35%となり、保持量の中央値は6,352 Bであった。EPOC の補助状態は $\delta$-Adapter、COSA、FAC、OMPB のいずれよりも少なく、各方式との対応比較で過半数の条件において MSE が低かった。ELF full は Static 比の平均 MSE をさらに大きい19.29%低減したが、保持量は EPOC の約75倍であった。別の共同学習群では、同じ基準予測器に適用した大域混合後の TEFL 型アダプタに比べて、EPOC は MSE を16.69～20.15%低減した。同容量の残差要約の対照では、端点を使うと対応 MSE が1.65～2.20%低かった。係数から復元した端点と入力除去の対照は、残差係数および現在予測の係数とともに、端点に相当する特徴を成分別回帰器の間で共有することが、観測された改善の多くを説明することを示す。$K$ を4から8に増やすと、保持量を5,728 B増やすことで、平均 MSE 低減率がさらに1.00ポイント上がった。これらの結果は、ブロック全体の正解が到着してから更新するオンライン補正において、EPOC が小さな保持量で得られる精度と保持量の一つの選択点を示している。

## 構造的な説明

| 論旨 | 結論で述べる内容 | 根拠 |
|---|---|---|
| 手法 | 低次 DCT 係数と直前残差の末尾値を保持し、現在予測の係数とともに成分別の逐次回帰へ入力する | III章 |
| 精度と保持量 | 96条件で Static 比 MSE 15.40%・MAE 9.35%低減、保持量中央値6,352 B。主要な比較器より小さい状態と、ELF full より小さい平均改善率を併記する | Table 3、Figs. 2・4 |
| 別実験群 | 同一の共同学習済み基準予測器上で TEFL 型アダプタと比べる。主比較の96条件とは集計しない | Table 4 |
| 端点と入力 | 同容量の要約対照は末尾値の選択を、復元端点と入力除去は端点型特徴の成分間共有と他の入力との組み合わせを支える | Table 5・Fig. 3 |
| 設定と結び | $K=4$ は最高精度ではなく保持量との選択である。完了ブロック後の更新という評価規約の下で結果を結ぶ | Fig. 4、IV章 |

本文の「15.40%・9.35%」と「19.29%」はそれぞれ Static を分母とする条件別低減率の平均である。「16.69～20.15%」は同じ共同学習済み基準予測器に適用したアダプタの損失を分母とし、「1.65～2.20%」は端点以外の同容量要約の損失を分母とする。

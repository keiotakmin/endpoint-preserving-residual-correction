## 日本語訳

### 付録A. 補足の数値記録

付属の CSV は、本文の表へ集計する前の損失を収録する。[tableS01_all_conditions.csv](figure/tableS01_all_conditions.csv) は固定基準予測器の96条件について各1行を持つ。`mse` と `mae` は EPOC の値である。`static` と `elf` の接頭辞は無補正の基準予測器と大域混合後の ELF full を表し、`independent_mse` は係数のみを使う補正の値である。百分率の列名の接尾辞は分母となる方式を示し、`trace_file` は保存済みのブロック損失を指す。七方式の [table03_all_conditions.csv](figure/table03_all_conditions.csv) は、Table 3 の各方式・各固定基準予測条件について1行、計672行を持つ。この CSV に残る方式名 `Proposed` は EPOC を表す。

七方式の CSV から Table 3 の全体表を再現するときは、方式ごとに96行の `mse_reduction_pct` と `mae_reduction_pct` を平均し、`state_bytes` の中央値を取る。系列・予測器別の MSE・MAE 表では、系列・予測器・方式の各組について三 seed と二つの基準予測器学習区分の元損失を平均する。`method` と `arm` は表示方式と予測の種類を示す。

[tableS02_learned_all.csv](figure/tableS02_learned_all.csv) は、六系列×二予測器×二 warmup×三 seed×三アダプタ幅×四予測方式の864行からなる。`rank` は幅、`kind` は warmup、`arm` は補正なしの共同学習済み基準予測器（`base`）、混合前アダプタ（`adapter`）、大域混合後のアダプタ（`adapter_global`）、大域混合後の EPOC（`boundary`）を示す。`state_bytes` は補正用の保持配列量なので、無補正の基準予測器では0となる。併設した [tableS02_width64_training.csv](figure/tableS02_width64_training.csv) は幅64の288行を持ち、Table 4 の学習比較に使う別学習の base-only 実行も含む。両 CSV の `bdg2` は BDG2 (Rat) を意味する。

Table 4 の同一基準予測器上の低減率を求めるときは、[tableS02_learned_all.csv](figure/tableS02_learned_all.csv) の各系列・予測器・warmup・幅・方式について三 seed の損失を平均する。その後、各指標と各12組で $100(1-m_{\mathrm{boundary}}/m_{\mathrm{adapter\_global}})$ を計算し、その12個の百分率を平均する。Table S1 は共通評価設定と共同学習の設定をまとめる。

**Table S1 のキャプション訳。** 補足記録で用いる共通評価設定と学習済みアダプタの学習設定。固定基準予測器の学習と比較器の規約はIV章に記す。

| 項目 | 設定 |
|---|---|
| 入力長 / 予測長 / 発行間隔 | 96 / 24 / 24 |
| EPOC の残差基底 | DCT、$K=4$ |
| ridge / 忘却 | $\lambda=1$、$\rho=2^{-1/128}$ |
| 混合窓 | 完了した32ブロック |
| 学習済みアダプタの幅 / seed | 2、4、64 / 0、1、2 |
| warmup / 共同学習 | 3 / 12 epoch |
| 共同学習の損失 / 最適化器 | MAE / AdamW |
| 学習率 / weight decay / バッチ | $10^{-3}$ / 0.01 / 32 |
| SF の重み / パワーの安定化値 | 1 / $10^{-8}$ |
| ELF 移植版の ridge | 非スケール化統計で $20\sigma_c^2I$、1ブロックにつき1窓 |
| チェックポイント選択 | 検証 MAE、epoch 0～12 |
| 保持量から除くもの | 基準予測器、観測履歴、予測・正解バッファ、一時配列、Python オブジェクトのオーバーヘッド |

### 付録B. 設定感度

Table S2 は Fig. 4 に示した13個の一因子設定を列挙し、対応する条件別の1,248行を [tableS05_sensitivity_conditions.csv](figure/tableS05_sensitivity_conditions.csv) に収録する。$K$ を1から8へ増やすと、Static 比の平均 MSE 低減率は11.13%から16.40%へ、保持量中央値は2,056 Bから12,080 Bへ増える。$K=4$ のまま ridge 係数、忘却半減期、混合窓を変更したときの平均 MSE 低減率は14.47～15.43%である。試した中で最も短い32ブロックの忘却半減期では15.43%、忘却なしでは14.47%となる。

## 構造的な説明

- **付録Aは本文の数値を追跡できる形で示す。** 固定基準予測器、七方式、共同学習群の条件別 CSV と集計規則を示す。Table S1 は結果の解釈に必要な評価・学習設定をまとめる。
- **付録Bは設定感度の詳細を示す。** Table S2 に Fig. 4 の13設定の集計値、付属 CSV に96条件それぞれの値を収録する。

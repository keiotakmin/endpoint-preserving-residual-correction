## 日本語訳

### V. 結果

#### A. 精度と保持状態

保持量の byte 数は、予測と予測の間に維持する補正パラメータ、最適化器のテンソル、回帰統計、残差の要約、方式固有のバッファ、および混合器の状態を数える。固定した基準予測器、共通の観測履歴、予測・正解のバッファ、一時作業領域は含めない。

Table 3 は、固定基準予測器の96条件で七方式を比較する。EPOC は Static に対して平均 MSE を15.40%、平均 MAE を9.35%低減し、保持量の中央値は6,352 Bである。$\delta$-Adapter、COSA、FAC、OMPB を分母とする EPOC の対応 MSE 低減率は、それぞれ9.55%、4.18%、0.92%、6.06%である。EPOC の MSE が低い条件数は、それぞれ96条件中84、77、58、91である。EPOC は96条件すべてで Static より MSE と MAE を低くする。ELF full は Static に対する平均低減率が最大で、MSE が19.29%、MAE が12.74%であり、保持量の中央値は474,048 Bである。EPOC の保持量中央値は ELF の約75分の1である一方、Static 比の平均 MSE 低減率は3.89ポイント小さい。

**Table 3 のキャプション訳。** 対応する96条件における七方式の比較。冒頭の全体表は条件別の Static 比低減率を平均する。保持量の括弧内は EPOC の6,352 Bを基準にした倍率を整数へ丸めたものである。MSE 表と MAE 表では、各系列・予測器の組について三 seed と `legacy`/`refit` の損失を平均する。最右列の比率は、丸め前の EPOC の損失を、その行の丸め前の最小損失で割った値であり、1なら最良である。太字は各行の最小損失と、EPOC が最良の場合の対応する比率を示す。すべての補正には共通の大域混合を適用する。

| 方式 | Static 比の平均 MSE 低減率 | Static 比の平均 MAE 低減率 | 保持量中央値 |
|---|---:|---:|---:|
| Static | 0.00% | 0.00% | 0 B (×0) |
| $\delta$-Adapter | 6.70% | 5.12% | 22,552,608 B (×3550) |
| COSA | 11.73% | 7.56% | 111,756 B (×18) |
| FAC | 14.59% | 9.11% | 33,312 B (×5) |
| OMPB | 10.05% | 6.73% | 767,216 B (×121) |
| ELF full | 19.29% | 12.74% | 474,048 B (×75) |
| EPOC | 15.40% | 9.35% | 6,352 B (×1) |

Table 3 の後半にある MSE・MAE の数値表は、八系列×二予測器の16行について七方式の絶対損失と、最右列 `EPOC/best` に EPOC と最良方式の損失比を示す。この比率が1を超える場合、1からの差が最良方式に対する EPOC の損失の超過率を表す。見出しの `Dataset` は系列、`Backbone` は基準予測器、`Static` は無補正を意味する。数値自体は [table03.csv](figure/table03.csv) でも確認できる。

Fig. 2 は八系列・二予測器にわたって平均 MSE 低減率と保持量がどう変わるかを示す。線分は、一つの系列で同じ方式を DLinear と PatchTST に適用した結果を結ぶ。EPOC は各パネルで、適合を行うオンライン方式のうち保持量が最も少ない側に位置する。誤差による順位は系列ごとに変わる。Fox では、COSA、FAC、$\delta$-Adapter のいずれも、両予測器で EPOC より MSE が低い。この関係は Table 3 の該当行にも表れる。ELF は Fox と Panther の両予測器で MSE が最小であり、その保持量は EPOC より大きい。

**Fig. 2 のキャプション訳。** 固定基準予測器の96条件における六つの補正方式の系列別精度と保持量。各マーカーは、一系列・一予測器の三 seed と二学習区分にわたる Static 比 MSE 低減率の平均である。丸印は DLinear、三角印は PatchTST を表す。線は同じ方式の二予測器を結ぶ。横軸は保持量中央値の byte 数を対数目盛で示す。

Table 4 は、共同学習済みの基準予測器上で EPOC と TEFL 型残差アダプタを比較する。六つの warmup・幅設定にわたり、**同じ共同学習済み基準予測器**の上で、大域混合後のアダプタを分母とした EPOC の MSE 低減率は16.69～20.15%、MAE 低減率は8.82～11.29%である。別の学習比較では、共同学習したアダプタの混合前の予測は、対応する base-only 学習実行より MSE を2.22～6.44%低くする。したがって、直接の補正比較では、base-only 学習より改善するアダプタを比較相手としている。EPOC の保持量は、共同学習群の各比較で4,528 Bである。大域混合後のアダプタの保持量中央値は、幅2、4、64でそれぞれ1,584 B、1,968 B、13,488 Bとなる。小幅アダプタは EPOC より少ない状態を使い、幅64のアダプタは多く使う。

#### B. 端点の選択と入力構成

Table 5 は、EPOC の回帰に入れる残差の要約を、保持量が等しい条件で比較する。固定基準予測器の96条件では、末尾値を保持すると、先頭値、中央値、ブロック平均を保持する場合に比べ、対応する平均 MSE がそれぞれ2.20%、1.65%、1.96%低い。対応する MAE 低減率は1.46%、1.11%、1.39%である。共同学習群でも、端点の改善率は各対照に対して正である。MAE warmup では MSE 低減率が4.70～6.00%、MAE+SF warmup では5.43～6.94%となる。同一条件内では端点版と三つの対照の保持 byte 数が等しいため、これらは回帰形と保持量を固定した上で、どのスカラー要約を選ぶかの比較である。

**Table 5 のキャプション訳。** 同容量の残差要約に対する端点の改善率。各セルは、直前ブロックの先頭残差、中央残差、または平均残差を末尾残差に置き換えたときの、MSE あるいは MAE の平均対応低減率を表す。固定基準予測器の行は96条件別の低減率を平均する。共同学習の各行は、先に三 seed の損失平均を作り、その後12個の系列・予測器組の低減率を平均する。一つの比較内では、基準予測器、回帰設定、混合規約、保持量が等しい。

Fig. 3 は同じ固定基準予測器の96条件において、回帰入力の全体を検討する。完全入力の Static 比平均 MSE 低減率は15.40%であり、端点なしは13.37%、残差 DCT 係数なしは13.87%、現在予測の係数なしは13.02%、端点のみは11.34%である。条件別に直接比べると、完全入力は端点のみの回帰より MSE を平均4.55%低くし、96条件すべてで勝る。保持した DCT 係数から復元した端点を与える場合、Static 比の平均 MSE 低減率は14.98%であり、実測端点を使う場合の15.40%に近い。この復元値を成分ごとの全回帰器に共有すると、端点入力を明示的に共有したときの改善の多くが得られる。保持量中央値は完全入力が6,352 B、復元端点が6,264 B、端点のみが2,832 Bである。

**Fig. 3 のキャプション訳。** 固定基準予測器の対応する96条件における入力構成。マーカーは条件別の Static 比 MSE・MAE 低減率の平均、棒は大域混合時の保持量中央値を示す。復元端点 $\tilde r$ は保持した残差 DCT 係数から計算し、成分ごとの全回帰器に入力する。端点の持続予測では適合する回帰器を使わず、直前の端点値を繰り返す。

#### C. 精度・保持量と設定感度

Fig. 4 の上段は、Table 3 の六つの補正方式を、MSE・MAE・保持状態の共通軸上に置く。EPOC は保持量中央値6,352 Bで平均 MSE を15.40%低減し、ELF full は474,048 Bで19.29%低減する。他の主比較方式のうち、平均 MSE 低減率が EPOC に最も近いのは FAC で、14.59%、33,312 Bである。これらの点は、対応比較の背後にある精度と保持量の選択関係を示す。

下段では同じ96条件について、EPOC の設定を一つずつ変える。$K$ を1から4に増やすと、平均 MSE 低減率は11.13%から15.40%へ、保持量中央値は2,056 Bから6,352 Bへ増える。$K=8$ では MSE 低減率が16.40%、保持量が12,080 Bとなる。$K=4$ から $K=8$ への追加の1.00ポイントの改善には、5,728 B の追加保持量が伴う。$K=4$ のまま ridge 係数、忘却半減期、混合窓を変えると、平均 MSE 低減率は14.47～15.43%の範囲に収まる。この一因子比較では、成分数が精度と保持量を最も大きく変える設定である。Table S2 は13設定の全体値を示し、対応するCSVに条件別の値を収録する。

**Fig. 4 のキャプション訳。** 固定基準予測器の96条件における主比較と一因子感度。上段は、大域混合を適用した六つの補正方式について、Static 比低減率の条件別平均と保持量中央値を示す。左下は保持する DCT 成分数 $K$ を変え、右下は $K=4$ の基準設定から ridge 係数、忘却半減期、混合窓を変えた結果を示す。変更しない設定はIII章の値を使う。


## 構造的な説明

- **RQ1（Tables 3–4、Fig. 2）：比較器との精度・保持量。** Table 3 で96条件の七方式を同じ分母で比較し、Fig. 2 で系列・予測器別のばらつきを示す。Table 4 は別の共同学習群に移り、EPOC 対アダプタには同じ共同学習済み基準予測を使う。アダプタ対 base-only は別の学習効果の比較である。
- **RQ2（Table 5 と Fig. 3）：端点と入力の役割。** Table 5 は保持量と回帰形を揃え、残差要約の位置・種類を替える。Fig. 3 は係数・端点・現在予測を組み合わせる入力構成を調べる。復元端点の結果は、端点値を成分間で共有する入力表現を読む鍵になる。
- **RQ3（Fig. 4、Table S2）：設定感度。** $K$ に伴う MSE 改善と保持量の増加を、ridge・忘却・混合窓の変化と比較する。Table S2 の要約と付属CSVは13設定・96条件の値を示す。

Table 3 と Figs. 2、3、4 の百分率は各条件で Static を分母として計算する。Table 3 の相手法への対応比較、Table 4 の同一基準予測上の EPOC 対アダプタ、Table 5 の端点対他の要約では、それぞれ名前を示した比較相手の損失が分母になる。Table 4 と Table 5 の共同学習群は三 seed の損失を組内で平均してから、12組の対応改善率を平均する。

## 図表の段組み

Tables 3–5 は複数の指標を見比べられるよう二段幅とした。Table 5 は三つの対照ごとに MSE・MAE の対応改善率と保持量を示す。Fig. 2 は八つの小パネル、Fig. 3 は入力構成の比較、Fig. 4 は四パネルで示す。補足の Table S2 は四列で一段幅に収まる。
